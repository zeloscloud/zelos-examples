# The shared bench script

A stand-in bench supply that serves actions and streams rail voltages. Used by [Send commands to your hardware from the app](https://zeloscloud.io/blog/send-commands-from-the-app), [Write your own action in nine lines of Python](https://zeloscloud.io/blog/write-your-own-action-in-python), [Build your own tab with live readouts and a command button](https://zeloscloud.io/blog/add-your-own-tab-to-zelos), [Pick the right panel for each signal](https://zeloscloud.io/blog/pick-the-right-panel).

Install the SDK with `pip install zelos-sdk`, start the Zelos app, then:

```bash
python bench.py
```
