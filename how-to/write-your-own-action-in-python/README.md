# Write your own action in Python

Code for [Write your own action in Python](https://zeloscloud.io/blog/write-your-own-action-in-python).

This folder is the project the post makes with `uv init bench` and `uv add zelos-sdk`. Install [uv](https://docs.astral.sh/uv/), start the Zelos app, then run in this folder:

```bash
uv run first_action.py
```
